# Ghostty Setting Reconstruction Spec

## Goal

Recreate the user's Ghostty terminal setup on a new machine using only this
folder. An agent should be able to read this spec and the checked-in config,
run the installer, and verify the result without access to the original host.

## Source of truth

- `config.ghostty` (repository root) is a verbatim copy of the observed live
  file `/home/ywchen/.config/ghostty/config.ghostty`.
- Observed with Ghostty `1.3.0-dev` on Linux. Keep the inline comments; they
  document why the settings exist.
- The live path is `${XDG_CONFIG_HOME:-$HOME/.config}/ghostty/config.ghostty`.
  Ghostty 1.3 uses the `config.ghostty` filename. On macOS it additionally
  searches `~/Library/Application Support/com.mitchellh.ghostty/config.ghostty`,
  but this kit intentionally targets the observed Linux/XDG path.

## Exact config

```ghostty
# Visual baseline: Catppuccin Mocha with breathing room.
# Manual byobu mode: no `command = ...` here, so new windows start in bash.
theme = Catppuccin Mocha
font-family = Ubuntu Mono
font-size = 11

# Points, DPI-scaled. Keeps text off the window edges.
window-padding-x = 8
window-padding-y = 6
window-padding-balance = true
window-padding-color = background
```

## Intent and semantics

| Key | Value | Intent |
| --- | --- | --- |
| `theme` | `Catppuccin Mocha` | Built-in theme; supplies the whole color scheme. `ghostty +show-config` expands this into `background = #1e1e2e`, `foreground = #cdd6f4`, and the Catppuccin palette. Do not add explicit colors. |
| `font-family` | `Ubuntu Mono` | Terminal font family. |
| `font-size` | `11` | Font size in points, DPI-scaled by Ghostty. |
| `window-padding-x` | `8` | Horizontal padding in points, DPI-scaled. |
| `window-padding-y` | `6` | Vertical padding in points, DPI-scaled. |
| `window-padding-balance` | `true` | Distributes leftover viewport space evenly instead of letting one edge hug the cell. |
| `window-padding-color` | `background` | Paints the padding area with the theme background rather than extending the nearest cell's background. |

Additional invariants:

- There is deliberately **no `command = ...`** line. Byobu is started manually;
  new windows start in the default shell (bash in the observed environment).
  Do not add an auto-start command.
- `ghostty +show-config` reports derived values such as `font-family-bold`,
  `font-family-italic`, `font-family-bold-italic`, and the expanded palette.
  These are generated by Ghostty, not drift; do not copy them into the file.
- `window-padding-color` may be omitted from `+show-config` when it matches the
  built-in default. The checked-in file is authoritative for that key.

## Installation contract

`./install.sh` is runnable from any working directory and must:

1. Resolve its own directory and read `config.ghostty` from there.
2. Require `HOME`; use `XDG_CONFIG_HOME` when set, otherwise `$HOME/.config`.
3. Create `${XDG_CONFIG_HOME:-$HOME/.config}/ghostty` if needed.
4. Be idempotent: if the destination is already byte-identical, print that it
   is up to date and make no changes.
5. If a different regular file or symlink exists, back it up to
   `config.ghostty.bak.<UTC timestamp>.<pid>` (preserving its mode/link), then
   install the source via a temporary file and atomic `mv`.
6. Never delete the original config without first creating a backup.
7. Print the destination path on success.

Non-goals: no shell profile edits, no byobu auto-launch configuration, no
macOS-path logic in the installer, no font/package installation.

## Verification

```bash
cd /path/to/ghosttly_setting

# 1. The checked-in config must be valid.
ghostty +validate-config --config-file=./config.ghostty

# 2. Install (safe to re-run).
./install.sh

# 3. The installed file must match the source exactly.
DEST="${XDG_CONFIG_HOME:-$HOME/.config}/ghostty/config.ghostty"
diff -u ./config.ghostty "$DEST"

# 4. Ghostty must report the effective visual settings.
ghostty +show-config | grep -E '^(theme|font-family|font-size|window-padding-(x|y|balance)) ='
```

Expected output from step 4 (order may differ):

```text
font-family = Ubuntu Mono
font-size = 11
theme = Catppuccin Mocha
window-padding-x = 8
window-padding-y = 6
window-padding-balance = true
```

Also confirm the file-level setting that may be hidden by `+show-config` defaults:

```bash
grep -F 'window-padding-color = background' "$DEST"
```

A successful reconstruction has an empty `diff`, a clean `validate-config`
exit, and all the lines above present.
